# Product Requirements Document (PRD)

## Project

KWT Website

## Purpose

Build the official website for **KWT | Kashmiri Women in Tech** to serve as the central platform for the community.

## Goals

- Introduce KWT
- Showcase events
- Share opportunities
- Provide resources
- Allow visitors to contact and join the community

## Pages

- Home
- About
- Events
- Resources
- Opportunities
- Contact

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- Vercel

## Future

- Spring Boot backend
- PostgreSQL
- Authentication
- Admin dashboard

# Contributing

## Workflow

- Create a new branch for every feature.
- Do not push directly to `main`.
- Open a Pull Request for review.
- Merge only after approval.

## Branch Naming

```text
feature/navbar
feature/homepage
feature/about-page
fix/mobile-navbar
chore/project-setup
```

## Commit Messages

```text
feat: add homepage hero
fix: resolve navbar alignment
chore: configure Tailwind CSS
docs: update PRD
```

## Guidelines

- Keep components reusable.
- Follow the design system.
- Write clean and readable code.
- Test changes before creating a Pull Request.

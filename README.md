# Kashmiri Women in Tech — Website

The official website for **Kashmiri Women in Tech (KWT)**.

KWT is a community focused on connecting Kashmiri women in technology through community, learning, opportunities, and meaningful connections.

## About KWT

Kashmiri Women in Tech is building a space where Kashmiri women interested in or working in technology can:

- Connect with other women in tech
- Discover jobs and opportunities
- Learn and grow together
- Attend events and community sessions
- Share knowledge and experiences
- Build meaningful professional connections

## About This Project

This repository contains the source code for the official KWT website.

The website provides information about KWT and serves as a central place for community members to discover:

- KWT's mission and vision
- Community events
- Opportunities
- Ways to get involved
- Team members
- Community initiatives

# KWT Website

Official website for **KWT | Kashmiri Women in Tech**.

## Tech Stack

- React (Vite)
- Tailwind CSS
- shadcn/ui
- React Router
- React Hook Form + Zod
- react-helmet-async
- Vercel

## Getting Started

```bash
git clone https://github.com/KashmiriWomenInTech/website.git
cd website
npm install
npm run dev
```

## Project Structure

```
src/
├── assets/
├── components/
├── pages/
└── App.jsx
```

## Workflow

- Create a feature branch.
- Open a Pull Request.
- Merge only after review.
- No direct pushes to `main`.
